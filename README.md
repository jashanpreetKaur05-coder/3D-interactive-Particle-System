# Interactive 3D Particles

## Overview

This project demonstrates an interactive 3D particle visualization where thousands of particles dynamically organize into different shapes and patterns. The simulation responds to user interaction, allowing particles to move and react in real time.

Users can explore different particle formations including **Cloud, Heart, Saturn, Flower, and Explode** modes. Mouse movement influences particle motion while clicks change particle color themes, creating a visually engaging and interactive animation.

---

## Features

* Interactive 3D particle system
* Multiple particle formation modes
* Real-time animation rendering
* Mouse interaction to attract particles
* Click interaction to change particle colors
* Smooth transitions between particle patterns

---

## Particle Modes

The visualization supports several particle configurations:

1. **Cloud** – particles move freely forming a soft cloud-like structure
2. **Heart** – particles arrange to form a heart shape
3. **Saturn** – particles create a planet with a surrounding ring structure
4. **Flower** – particles organize into a flower-like pattern
5. **Explode** – particles disperse outward dynamically

---

## Controls

| Action      | Function                            |
| ----------- | ----------------------------------- |
| Move Mouse  | Attract particles toward the cursor |
| Click Mouse | Change particle color scheme        |
| Keys 1–5    | Switch between particle modes       |
